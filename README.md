# 应统择校 · MAS Choice

**应用统计专硕（025200）择校数据平台**：复试线、初试科目、参考书风格，逐条标注来源，可筛选、可对比、可看趋势。

**在线使用**：<https://cloud1-d4gsgj705497df85d-1501559031.tcloudbaseapp.com/mas-choice/>

## 它解决什么问题

应用统计专硕是近年最热门的考研专业之一，但择校信息散落在各校研究生院官网、研招网和零散的知乎文章里：没有统一的口径、没有结构化的对比、更没有标注"这条数据到底哪来的"。

应统择校把它做成一个**数据产品**：

1. **择校表**：30+ 院校的结构化数据，按地区 / 层次 / 分数段筛选，按校名搜索，按复试线排序；每条数据标明「✓ 已核实」（院校官网或多来源交叉）或「单一来源」（仅第三方来源，使用前请自行核对）。
2. **对比**：勾选 2–3 所院校，横向对比复试线变化、初试科目、参考书风格、拟招生人数。
3. **分数线趋势**：应用统计国家线（A区）历年走势 + 各校 2024 vs 2025 复试线分组对比。
4. **数据说明**：更新日期、核实口径、空值处理规则、免责声明。

## 数据原则

- **每个数字都有来源**：复试线优先取院校研究生院/学院官网公示，其次研招网与权威站点，来源链接直接附在页面上。
- **不猜、不编、不插补**：查不到的数据显示为 —，绝不填一个"看起来合理"的数。
- **诚实标注不确定性**：单来源与多来源交叉的数据用不同标识区分。
- 复试线每年浮动，本工具是信息整理助手，**填报志愿请以院校官方最新公告为准**。

## 技术实现

- 纯前端单页应用：原生 HTML/CSS/JS + Apache ECharts（本地打包），零构建、零后端、零成本运维。
- 数据层：`tools/build_data.py` 把采集核实的 JSON 生成静态 `data.js`；更新数据只需重跑脚本再部署。
- 部署：腾讯云 CloudBase 静态托管，独立子域名，手机可直接访问。
